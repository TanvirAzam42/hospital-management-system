 🏥 Smart Hospital Management System

A professional desktop Hospital Management System built with **Python Tkinter + SQLite**.
 🚀 Features

 🔐 Authentication
- Secure Login
- SHA-256 Password Hashing
- Role Based Access (Admin / Receptionist)

👥 Staff Management
- Add Staff
- Delete Staff
- Change Role
- Reset Password

🧑‍⚕️ Patients Management
- Add Patient
- Update Patient
- Delete Patient
- Search Patient

👨‍⚕️ Doctors Management
- Add Doctor
- Update Doctor
- Delete Doctor
- Search Doctor

📅 Appointments
- Book Appointment
- Update Appointment
- Cancel Appointment
- Search Appointment
- Registered Doctor Dropdown

💵 Billing
- Generate Bill
- PDF Receipt Export

🎨 UI
- Dark Professional Theme
- Modern Login Screen
- Sidebar Navigation

---

🛠 Tech Stack

- Python 3.x
- Tkinter
- SQLite3
- ReportLab
